SPACE-SHOOTER 🚀

A modern recreation of the classic arcade space shooter built with C/C++ and SFML, showcasing object-oriented programming principles.

🔹 Features

Smooth 2D gameplay with SFML

Player-controlled spaceship with shooting mechanics

Enemy spawning and wave progression

Collision detection and scoring system

Modular, object-oriented design for easy expansion

🔹 Tech Stack

Language: C/C++

Framework: SFML (Simple and Fast Multimedia Library)

This project is both a fun retro-style game and a demonstration of applying OOP design patterns (inheritance, encapsulation, polymorphism) in a real-world C++ game development scenario.
